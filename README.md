## Почему этот инструмент

Я выбрал современный чистый CSS, потому что он позволяет создавать адаптивные страницы без дополнительных библиотек и сборки. CSS Grid подходит для сеток карточек, а Flexbox — для меню и выравнивания элементов. Переменные в `:root` помогают хранить основные цвета, отступы и размеры в одном месте. В проекте используется CSS nesting, который позволяет писать связанные правила рядом, и container queries, которые меняют оформление карточки в зависимости от размера её контейнера. В отличие от Bootstrap, здесь нет готовых компонентов, поэтому внешний вид можно настроить полностью под дизайн. При этом чистый CSS требует самому продумывать компоненты, состояния и адаптивные правила.

## Современные возможности CSS

- CSS-переменные в `:root` — цвета, ширина контента и отступы.
- `clamp()` — плавно меняет размер заголовков в зависимости от ширины экрана.
- CSS nesting — вложенные правила для ссылок меню.
- Container queries — оформление карточек зависит от ширины контейнера.
- CSS Grid и Flexbox — адаптивная сетка и расположение элементов.
- `:has()` — выбор карточек, содержащих элемент `.feature-icon`.
